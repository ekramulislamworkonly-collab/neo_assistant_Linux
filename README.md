# 🤖 Neo Assistant

Neo Assistant is a terminal-based Linux automation assistant built using Bash scripting.  
It automates common Linux tasks through an interactive command-line interface and helps improve productivity with simple system management features.

---

# 🚀 Features

- ✅ System Update Automation
- ✅ Internet Connectivity Checker
- ✅ RAM Usage Monitor
- ✅ Disk Usage Monitor
- ✅ Weather Reports
- ✅ Open Applications from Terminal
- ✅ Temporary File Cleaner
- ✅ Interactive Menu-Driven Interface
- ✅ Colored Terminal Output

---

# 🛠 Technologies Used

- Bash Scripting
- Linux Commands
- Shell Automation
- Terminal Utilities
